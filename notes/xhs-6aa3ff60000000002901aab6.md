智力题：100 个 GPU 找任务包
	
有 100 个 GPU，编号为 0 ~ 99。同时有 100 个任务包，每个任务包上标有一个 GPU 编号，并且 0 ~ 99 每个编号恰好出现一次。
	
这 100 个任务包被随机放到 100 个 GPU 上，每个 GPU 上恰好放一个，因此任务包的位置实际上构成了一个随机排列。
	
对于 GPU i，它的目标是找到编号为 i 的任务包。
	
每个 GPU 最开始从自己的位置出发。它每查看一个位置，就能看到该位置任务包上的编号，并据此决定下一步去查看哪个 GPU 上的任务包。每个 GPU 最多只能查看 50 个位置。
	
所有 GPU 可以提前约定同一种策略，但搜索过程中不能互相通信，也不知道其他 GPU 查到了什么。
	
问：
	
1. 是否存在一种策略，使得“100 个 GPU 全部在 50 次以内找到自己的任务包”的概率，远高于每个 GPU 随机选择 50 个位置？
2. 如果有，这个策略是什么？
3. 整体成功概率大约是多少？
