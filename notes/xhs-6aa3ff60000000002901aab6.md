阿里妈妈 Infra 一面，主要讨论项目，基础问题较少。

1. 世界模型 / VAE 并行：候选人此前直接对 VAE 做 spatial 切分，未使用 halo exchange 等无损方案；面试官从其专业领域出发进行了追问。
   - 候选人反馈：认为简历中这部分的表述需要重新斟酌。
2. 编程：使用 CUDA 实现 Online Softmax。
3. 智力题：100 个 GPU 寻找任务包。
   - 100 个 GPU 编号为 0～99；100 个任务包也分别标有 0～99，每个编号恰好出现一次。任务包随机分配到 GPU，每张卡恰好放一个，位置构成随机排列。
   - GPU i 要找到编号为 i 的任务包，从自己的位置开始。每查看一个位置，就可看到该任务包上的编号，并据此决定下一步查看哪个 GPU 上的任务包；每个 GPU 最多查看 50 个位置。
   - 所有 GPU 可以事先约定同一种策略，但搜索过程中不能相互通信，也不知道其他 GPU 的搜索结果。
   - 是否存在一种策略，使所有 GPU 在 50 次以内找到各自任务包的概率远高于每个 GPU 随机选择 50 个位置？如果有，策略是什么？整体成功概率约为多少？

候选人认为第 3 题是随机排列中的置换环 / cycle decomposition 问题，属于经典 100 prisoners problem 的变体；据面试官说，该题可能由 AI 生成。候选人对面试中遇到该题感到意外。
