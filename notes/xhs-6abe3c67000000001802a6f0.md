Kimi AI Infra 一面。

1. DeepEP normal mode 与 low-latency mode 有什么区别？
   - 候选人记录：Normal 用于训练 / Prefill，吞吐优先，rank-major 去重；Low-latency 用于 Decode，延迟优先，不要 d2h。
2. Ulysses SP 和 Ring Attention 有什么区别？
   - 候选人记录：Ulysses 使用 All-to-All；Ring 传递 KV，可重叠通信与计算。
3. DCP 如何实现？
   - 候选人记录：KV 按 sequence 分片；通信 Q，各 Rank 计算 partial attention，最后 merge O / LSE。
4. Online Softmax / LSE merge 如何实现？
   - 候选人记录：running max + rescale + 加权合并。
5. Ampere → Hopper → Blackwell 有什么变化？
   - 候选人记录：cp.async / MMA → TMA / WGMMA → TCGEN05 / Tensor Memory；越来越强调异步编程和显式 software pipeline。
6. Tensor Memory 如何实现 pipeline？如何选择 num_stages？
   - 候选人记录：double buffer；结合计算 / 访存比例和片上资源约束。
7. register / shared memory 如何影响 occupancy？Persistent Kernel 如何隐藏 latency？
   - 候选人记录：影响 resident CTA / warp 数；Persistent Kernel 更依赖 Kernel 内的 software pipeline。
8. Grouped GEMM 的 contiguous / masked 有什么区别？tile 如何调度？
   - 候选人记录：动态 M / padding；tile scheduling；swizzle / L2 reuse。
9. MXFP8 和 block-wise FP8 有什么区别？
   - 候选人记录：量化粒度、scale 开销，以及 scale 与 MMA 的 overlap。
10. 如何选择 TMA 和 cp.async？
    - 候选人记录：TMA 适合规则 tensor tile；cp.async 更灵活。
