# 一面

技术面，只有一位技术面试官。

1. 自我介绍。
2. 简历中提到对 CUDA 算子进行深度定制与调优，具体做了哪些修改？
3. 简历中提到剖析性能，主要使用什么工具、如何使用、重点关注哪些指标？
4. 简历中提到三维重建，介绍技术实现过程及难点。
5. 是否了解 MLIR 和 PyTorch 的编译过程？在研究项目中训练模型时，是否做过底层训练加速？
6. 是否了解 CUDA 架构？
7. 高性能模型推理框架开发中遇到过哪些难点？
8. 反问环节：还有什么想问的？

候选人反馈：面试没有问八股，关注的都是 AI Infra 相关内容。第 5～7 题回答得不好，因此向面试官询问自己从事该职业还欠缺哪些能力、需要学习什么。候选人表示一面结果不理想。

# 二面

一位技术面试官，面试约 15 分钟。面试官主要询问简历项目中的难点和亮点，尤其是模型推理相关内容，而非采用一问一答的形式。

1. 项目中有哪些能体现个人能力的亮点？
2. 项目中的难点是什么？如何解决？
3. Flash Attention 的原理和实现过程是什么？
4. 模型推理框架中编写和优化了很多算子，选择一个算子介绍其实现与优化过程。
5. 对 GPU 架构了解多少？为什么通常在一个 block 中开启 128 或 256 个线程？
6. C++ 的构造函数、析构函数、成员函数、模板函数中，哪些可以写成虚函数，哪些不能？为什么？
7. 是否了解 warp 中的 bank 冲突？
8. 反问环节：还有什么想问的？

候选人反馈：二面结果不理想。
