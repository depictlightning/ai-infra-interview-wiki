1. MoE 的 EP、去重和 overlap 如何理解？
2. DiT / AR 与 Ulysses / Ring 有什么关系或区别？
   - 候选人记录：DiT 反复扩散、序列较长；AR 分为 Prefill 和 Decode，涉及 KV Cache 与调度。Ulysses 使用 All-to-All 重排 sequence / head；Ring 沿设备环传递 KV。
3. Linear Attention 在 Prefill 和 Decode 中如何执行？
   - 候选人记录：Hybrid 模型通常混合 full attention 和 linear attention，并非所有层都没有 KV Cache。Prefill 在 chunk 内并行、chunk 间传播 state；Decode 每 token 进行 streaming update。瓶颈转向 state / HBM 读写、归约、gating 的 SFU 开销和 small-batch launch。
4. LLM batching 与调度分别优化什么？
   - 候选人记录：continuous batching 支持动态进出，chunked prefill 切分长 Prefill，token budget 控制每轮计算。TTFT 关注首 token，TPOT / ITL 关注 token 间隔；需区分 token/s、request/s 和 goodput。
5. 编程：N 很大的 1D Softmax 如何实现？类似对很大的 N 做 reduce。原文提到“两个 kernel 版本”，随后记录了三个 kernel 的方案：
   - kernel 1：分小块分别计算，得到局部 m 和 l，可使用 online softmax 或其他方法。
   - kernel 2：使用一个 block 合并之前各小块的 m 和 l。
   - kernel 3：根据最终的 m 和 l 得到 softmax 结果。
