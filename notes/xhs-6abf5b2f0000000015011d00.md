原帖正文（待进一步规范表达）：

* DiT / 视频生成和 LLM 推理的优化重点有什么区别？
* DiT 更像超长 Prefill，长 sequence + 多 step，重点偏计算 / Attention 优化
* LLM 还有 Decode，涉及 KV Cache，调度等更多系统问题
* TP / SP / CP / EP 分别怎么切，通信开销是什么？
* TP：tp / tpsp
* Ulysses SP：核心是 All-to-All，通信少
* Ring CP：KV 分片并沿 Ring 通信
* EP：核心是 dispatch / combine
* Prefill CP 和 Decode CP 有什么区别？
* Prefill：可以 Ring 传 KV，边通信边计算
* Decode：历史 KV 很大，更适合保持 KV 分片、通信小得多的 Q
* Prefill / Decode 的特点和优化方向？
* Prefill：偏 compute-bound
* Decode：偏 memory-bound，重点包括KV Cache、调度等
* PagedAttention 解决什么问题？
* KV Cache 分页管理，减少内存碎
* Prefix Cache 是什么？
* 命中相同 prefix 时复用已有 KV Cache，减少重复 Prefill 计算
* 量化的收益有哪些？
* 提高 Tensor Core 计算吞吐
* 减少 memory traffic
* 降低显存占用，从而支持更长 context / 更大 batch
* NVFP4 / MXFP4 / block-wise FP8 有什么区别？
* 主要关注数据格式、group size / block size、scale 格式和两级量化
* Roofline Model 怎么分析 Kernel？
* Arithmetic Intensity 对比硬件 ridge point，判断 memory-bound / compute-bound
* HBM / Shared Memory 访存分别要注意什么？
