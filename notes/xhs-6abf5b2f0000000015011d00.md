1. DiT / 视频生成和 LLM 推理的优化重点有什么区别？
   - 候选人记录：DiT 更像超长 Prefill，sequence 长、step 多，重点偏向计算和 Attention 优化；LLM 还有 Decode，涉及 KV Cache 和调度等系统问题。
2. TP、SP、CP、EP 分别如何切分，通信开销是什么？
   - 候选人记录：TP 为 tp / tpsp；Ulysses SP 以 All-to-All 为核心，通信较少；Ring CP 将 KV 分片并沿 Ring 通信；EP 以 dispatch / combine 为核心。
3. Prefill CP 和 Decode CP 有什么区别？
   - 候选人记录：Prefill 可以 Ring 传递 KV，边通信边计算；Decode 的历史 KV 很大，更适合保持 KV 分片并通信小得多的 Q。
4. Prefill 和 Decode 的特点及优化方向是什么？
   - 候选人记录：Prefill 偏 compute-bound；Decode 偏 memory-bound，重点包括 KV Cache 和调度。
5. PagedAttention 解决什么问题？
   - 候选人记录：分页管理 KV Cache，减少内存碎片。
6. Prefix Cache 是什么？
   - 候选人记录：命中相同 prefix 时复用已有 KV Cache，减少重复 Prefill 计算。
7. 量化有哪些收益？
   - 候选人记录：提高 Tensor Core 计算吞吐，减少 memory traffic，降低显存占用，从而支持更长 context 或更大 batch。
8. NVFP4、MXFP4、block-wise FP8 有什么区别？
   - 候选人记录：关注数据格式、group size / block size、scale 格式和两级量化。
9. 如何使用 Roofline Model 分析 kernel？
   - 候选人记录：将 arithmetic intensity 与硬件 ridge point 对比，判断 memory-bound 或 compute-bound。
