本场从项目切入，延伸到推理框架、CUDA Graph、确定性计算、量化和 RL Infra。

1. MoE Router Replay 如何接入 RL 流程？为什么能降低训推不一致？rollout 端的 Top-K 路由信息如何记录、如何随数据传给训练侧、如何在 CPU / GPU 之间搬运？

3. TP + CUDA Graph 卡死问题：如何从大规模问题缩小到 TP=1 / TP>1 的对比？为什么 Graph 可能只是触发条件，真正的问题可能出在被替换的融合通信路径？capture / replay 有哪些约束，例如 kernel、shape 和地址中哪些必须稳定？
4. 确定性 Router GEMM：为什么 Split-K 会导致结果不完全一致？为什么固定配置在 Decode 的小 M 场景下浪费资源？如何设计动态选配置及回退路径？
5. Decode 融合算子、量化和模型结构：如何减少 CPU / GPU 往返同步？介绍 W4A16、AWQ、QAT、MHA、GQA，以及对 RL 框架的理解。
