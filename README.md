# AI Infra Interview Wiki

一个持续整理 AI Infra 真实面试经验的知识库，按公司、岗位和发布时间浏览，帮助求职者更高效地了解面试中实际讨论的问题。

## 我们想解决什么问题

AI Infra 覆盖训练、推理、算子、通信和集群等多个方向。面经散落在不同平台，有的题目藏在图片里，有的把候选人的回答和面试官的问题混在一起；只看搜索摘要，容易遗漏追问和上下文。这个项目尝试把分散的信息整理成可浏览、可追溯的面试记录。

## 项目特点

- **按面经保留上下文**：尽量保留问题顺序、追问、限定条件和候选人的反馈，不把每篇面经压缩成几个主题词。
- **适度规范表达**：将过于口语化的内容整理成清晰的编号和书面表述，不改变原意。
- **来源可追溯**：每篇记录保留原帖入口和已知发布时间；发布日期不等同于面试日期。
- **覆盖多个 AI Infra 方向**：包括分布式训练、推理系统、GPU 算子与性能优化、通信和算力调度等。
- **轻量且可本地使用**：Markdown 保存正文，静态网页提供公司目录、搜索和年份筛选；无需数据库或云服务。
- **明确不确定性**：候选人的回答和评价不视为标准答案；图片内容未核对时会注明，便于读者自行回原帖确认。

## 如何使用

克隆仓库后，在项目目录执行：

```bash
python local-data/import-sample.py
```

然后在浏览器打开 `dist/index.html`，按公司浏览，或使用搜索框和年份筛选。部分小红书原帖可能需要登录或在站内搜索才能访问。

## 目录说明

- `notes/`：逐篇整理的面经 Markdown，是正文的内容源。
- `local-data/sample-metadata.json`：公司、岗位、日期、标签与来源索引。
- `local-data/import-sample.py`：根据索引和 Markdown 生成网页数据。
- `dist/`：静态网页及生成的数据。

本仓库不包含登录状态、采集原始文件和原帖图片。内容来自公开分享，属于候选人的个人回忆，不代表公司官方题库或固定面试流程；请结合原帖和实际情况判断。
